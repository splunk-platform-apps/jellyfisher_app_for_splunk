# Binary File Declaration

The jellyfish library (https://pypi.org/project/jellyfish/1.2.1/, MIT license) ships a compiled module written in Rust. The source code is at https://github.com/jamesturk/jellyfish. The files below are the unmodified binaries of the jellyfish 1.2.1 wheels published on PyPI, one per platform and Python version supported by the app.

lib/3rdparty/linux_x86_64/python39/jellyfish/_rustyfish.cpython-39-x86_64-linux-gnu.so -- Compiled jellyfish module, Linux x86_64, Python 3.9
lib/3rdparty/linux_x86_64/python313/jellyfish/_rustyfish.cpython-313-x86_64-linux-gnu.so -- Compiled jellyfish module, Linux x86_64, Python 3.13
lib/3rdparty/windows_x86_64/python39/jellyfish/_rustyfish.cp39-win_amd64.pyd -- Compiled jellyfish module, Windows x86_64, Python 3.9
lib/3rdparty/windows_x86_64/python313/jellyfish/_rustyfish.cp313-win_amd64.pyd -- Compiled jellyfish module, Windows x86_64, Python 3.13
lib/3rdparty/darwin_x86_64/python39/jellyfish/_rustyfish.cpython-39-darwin.so -- Compiled jellyfish module, macOS x86_64, Python 3.9
lib/3rdparty/darwin_x86_64/python313/jellyfish/_rustyfish.cpython-313-darwin.so -- Compiled jellyfish module, macOS x86_64, Python 3.13
